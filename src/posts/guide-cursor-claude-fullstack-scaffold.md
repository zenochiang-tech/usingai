> 软件开发的「从零到一」阶段，从来都是效率最低的阶段。
>
> 项目结构、数据库连接、身份认证、API 路由……每一个重复的初始化动作都在消耗着开发者最宝贵的创造力。而 **Cursor + Claude** 的深度组合，正在将这一切压缩到近乎消失。
>
> ### 1. Cursor Rules 定义项目基因
>
> 在项目根目录创建 `.cursorrules` 文件，将你的技术栈偏好、命名约定与代码风格固化下来。一旦配置完成，Cursor 中的所有 AI 补全都会严格遵循这份"项目基因"，确保多人协作时的一致性。
>
> ```
> # .cursorrules 示例
> - 使用 TypeScript strict 模式
> - 组件使用 Server Component 优先策略
> - 数据库 ORM 统一使用 Drizzle + PostgreSQL
> - 所有 API 路由需包含 Zod 参数校验
> ```
>
> ### 2. 结构生成 Prompt 模板
>
> 通过一段精心设计的「脚手架 Prompt」，让 Claude 直接输出完整的目录树与核心文件内容：
>
> > *「基于以上 .cursorrules，为一个具备用户注册登录、内容发布与邮件通知功能的 SaaS 平台生成完整的 Next.js 14 App Router 项目结构，包含所有必要的配置文件与初始化代码。」*
>
> ### 3. 迭代而非重写
>
> AI 辅助开发的核心哲学：**永远在现有代码基础上迭代**，而非全量重写。每次只向 AI 提出一个明确、边界清晰的小需求，让修改范围可控、可审查。
>
> 工具链越成熟，创意空间越广阔。
>
