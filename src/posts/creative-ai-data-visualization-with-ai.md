> 数据，是这个时代最被低估的艺术素材。
>
> 过去，将数据转化为漂亮的交互式可视化图表，需要掌握 D3.js、Python Matplotlib 或 ECharts 等专业技能。而今天，一段精心设计的提示词，就能让 AI 完成从数据理解到代码生成的全链路创作。
>
> ### 1. 提示词设计的三个关键维度
>
> - **数据结构声明**：清晰描述数据的维度、字段类型与数量级，帮助模型理解数据的形状。
>   > *例：「这是一份包含 12 个月销售额与用户增长率的双轴时序数据」*
>
> - **视觉风格锚定**：指定目标图表类型、配色方案与交互行为（如悬停 tooltip、缩放联动）。
>   > *例：「使用赛博朋克深色主题，主色 #00f3ff，使用折线+面积图叠加，支持时间轴缩放」*
>
> - **输出格式约束**：要求模型直接输出可运行的完整 HTML 或 Vue 组件代码，而非伪代码。
>
> ### 2. 工具链推荐
>
> - **Claude + Artifacts**：实时预览生成的交互式图表，支持多轮迭代修改。
> - **ChatGPT Code Interpreter**：上传 CSV 直接生成 Python 可视化代码并即时渲染。
> - **Cursor + ECharts**：在 IDE 内通过 AI 补全构建企业级数据大屏。
>
